# Ren'Py 实时翻译工具（Renpy_RT_Tool）

昴娘个人独立开发 · 完全免费开源

一个 **Ren'Py 游戏**实时翻译工具。选中游戏的 exe，点开始翻译 —— 游戏里的
**英文 / 日文实时替换成中文**：正文、旁白、人名、选项、按钮、物品与任务说明、
设置页，全都在范围内。

**完全离线运行**：翻译模型就在 `models\` 文件夹里，不需要联网，不需要安装任何环境。
**即点即翻**：切到哪里翻哪里，不用整包翻译游戏。
**只加不改**：游戏原有文件一个都不动，只往 `game\` 目录新增翻译钩子与中文字体。

---

## 两个版本

同一套代码、同一套实时翻译链路，只有随包模型不同（模型内置定死，界面不提供选择）：

| 版本 | 随包模型 | 包大小 | 速度 | 适合 |
|---|---|---|---|---|
| `RENPY_RT_Tool`（轻量版） | Qwen2.5-1.5B-Instruct | 约 1.1 GB | 约 0.5 秒/句 | 老机器 / 想最快 |
| `RENPY_RT_Tool_Big`（大模型版，**推荐**） | Qwen3-4B-Instruct-2507 | 约 2.4 GB | 约 1.3 秒/句 | 要中文质量 |

机器不新 / 想最流畅 → 轻量版；想读得舒服、少看到错译 → 大模型版。

## 使用方法（两步）

1. **双击** `RENPY_RT_Tool.exe`（首次启动会弹《使用许可与禁止事项》，点「同意并继续」）
2. 点「**选择游戏…**」选游戏目录里的那个 **exe**（和 `game` 文件夹同级的那一个，
   例如 `…\游戏名\游戏名.exe`），再点「**▶ 启动游戏并开始实时翻译**」

没有第三步。工具会自己把翻译钩子装好、把本机翻译服务起来、再把游戏打开。

> 第一次启动会加载离线模型，约 10~30 秒（日志里有提示），别急着关。

**翻译效果**：游戏里的文字**先显示原文，约 1 秒后自动变成中文**；同一句第二次出现**秒出**。
主菜单里那些"图片按钮"（新游戏 / 加载游戏 / 选项 …）也单独处理成了中文。

## 文件说明

| 文件/文件夹 | 说明 |
|---|---|
| `RENPY_RT_Tool.exe` | 主程序（双击运行） |
| `_internal\` | 程序运行库，别删、别动 |
| `rt_mod\` | 注入游戏用的翻译钩子与中文字体，别删 |
| `models\` | 离线翻译模型（整个工具离线就靠它），别删 |
| `config.json` | 你的上次设置（端口、游戏路径等），可删 |

点「启动游戏并开始实时翻译」时，只会往游戏 `game\` 目录里**新增**：

```
game\zz_rt_translate.rpy     翻译钩子（核心）
game\zz_rt_mainmenu.rpy      主菜单图片按钮汉化（游戏主菜单是图片按钮时才有）
game\zz_rt_cjk.ttf           中文字体（Noto Sans CJK SC，OFL）
rt_translate\                译文缓存 cache.json / 开关 config.json / 日志 rt_log.txt
```

**卸载**：把上面那三个文件（连同同名 `.rpyc`）删掉即可，游戏立刻恢复原样；
想彻底干净，再删掉 `rt_translate\` 文件夹。

## 常见问题

**Q：点了开始，游戏起来了但一个字都没翻。**
A：看日志里有没有"翻译服务已就绪"。没有就是服务没起来（多半是模型加载失败）。
再看 `rt_translate\rt_log.txt`，出现"翻译服务连不上"就是端口不一致。

**Q：中文变方块 □。**
A：`game\` 下少了字体文件。重新点一次「启动游戏并开始实时翻译」即可补齐。

**Q：主菜单还是英文。**
A：少数游戏的主菜单是自己画的图片按钮（英文印在图片上），这类翻不了。
正文和其它菜单文字不受影响。

**Q：某句话翻得不对 / 有点慢。**
A：机翻是实时的，慢的那一下是在等模型；同一句第二次就秒出。
不满意的句子可以直接改 `rt_translate\cache.json`（明文 `原文: 译文`，改完重启游戏生效）。

**Q：会不会改坏游戏文件？**
A：不会。工具只往游戏目录**新增**文件，从不动游戏原有文件。

**Q：能不能不联网？**
A：本来就全程离线，不访问网络，不上传任何游戏或文本内容。

**Q：能翻哪些游戏？**
A：Ren'Py 引擎的游戏（有 `game\` 目录 + `.rpa` 包或散装 `.rpy`）。
选 exe 时如果提示"找不到 game 目录"，就是选错了 —— 要选和 `game` 同级的那一个。
